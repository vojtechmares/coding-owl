# Coding Owl is archived

Coding Owl is no longer developed.

## Why

Coding Owl did not fulfill its core loop: queue a piece of work, walk away
while the machine is idle, and come back to a verified branch ready for
review.

After careful evaluation, I decided against pivoting Coding Owl or refactoring
it into something else. Instead, I am building something new from scratch,
with the lessons learned here.
